# 🎓 Control de Materias Electivas

Sistema desarrollado en **C# (WinForms)** con **SQL Server** para gestionar materias electivas, controlar vencimientos y administrar resoluciones en PDF.
---
## 🚀 Funcionalidades

- 📚 Alta, baja y modificación de materias
- ⏰ Avisos automáticos (6 y 12 meses antes del vencimiento)
- 📧 Envío de correos de aviso
- 📄 Carga y visualización de resoluciones en PDF
- 🔗 Asociación de PDFs mediante Web API
---
## 🛠️ Tecnologías
- C# (.NET WinForms)  
- SQL Server  
- ASP.NET Core Web API  
- ADO.NET
